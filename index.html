GUÍA RÁPIDA DE USO:
1. Fecha:

Seleccionar la fecha del turno con el selector de fecha del encabezado.

2. Previsión:

Escribe la suma tal cual la apuntas en el papel, por ejemplo: 5+20+2+16+5+6. El Total se calcula automáticamente debajo.

3. Colirios:

Pulsa en + o - para ajustar las unidades de cada colirio. Puedes escribir también una fecha de caducidad o nota en la casilla inferior (por ejemplo: 30/08/26).

4. Servicios:

Pulsa + o - en cada fila (Sala, HDM, Otros, HDO) para contar pacientes y elaboraciones. También puedes escribir el número directamente.

5. Totales:

Los totales de Pacientes, Elaboraciones y Colirios se suman automáticamente.

6. Copiar:

Pulsa Copiar Resumen para copiar un texto con todos los datos. Luego puedes pegarlo en WhatsApp, un correo o donde necesites.

7. Excel:

Pulsa Exportar Excel para descargar un archivo con todos los datos del turno.

8. Nuevo turno:

Al finalizar, pulsa Reiniciar Turno para empezar de cero con el siguiente turno.

IMPORTANTE - Dónde se guardan los datos:

Los datos se guardan en este mismo ordenador, dentro del navegador (Chrome, Firefox, Edge...). No hay un servidor ni una base de datos en internet.

• Si vuelves a abrir esta página en el mismo PC y el mismo navegador, los datos seguirán ahí.

• Si abres la página en otro PC u otro navegador, los datos NO aparecerán porque están guardados solo aquí.

• Si alguien borra el historial del navegador, los datos también se perderán.

• Por eso es importante usar Exportar Excel o Copiar Resumen para tener una copia fuera de la aplicación.
